# ratcount · 功能测试案例（Functional Test Cases）

> 版本：v1.1 ｜ 范围：端到端业务流程 ｜ 执行方式：手动 + 浏览器
> 演示账号：`admin@example.com` / `demo1234`（验证码可点击刷新）

## 一、概述

功能测试覆盖系统核心业务闭环：认证、记账、账户、分类/标签/项目、余额对账、报表、日志、设置、导入导出、账本隔离、收支日历、周期计划。所有**写操作**（增/删/改/复制/批量/退出）必须弹确认框，确认后才执行。审计日志仅记录 **C/U/D 写操作**，查询（R）类操作不记录。
