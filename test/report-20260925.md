## 一、本次变更概述

- **新增账户类型「消费型保险」**（`consumption_insurance`）：类型保留、可在 `/accounts` 选建账户，但**不归入保障 / 投资**（`PROTECTION_ACCOUNT_TYPES` 维持 5 类，与「个人养老金」「社保」等保障类型并列展示；消费型保险为普通消费账户类型，不计入 `/protection` 总览）。
- 三语文案：`acctType.consumptionInsurance` = 消费型保险 / 消費型保險 / Consumption Insurance；图标 `🧾`。
- 消费方（`account-type-select` 遍历 `ACCOUNT_TYPES`、`protection/page.tsx` 用 `PROTECTION_ACCOUNT_TYPES` 驱动汇总与新增）数据驱动自动生效，**无需改动 UI / action**。
- 不纳入投资类账户、不新增演示种子账户（与社保口径一致）。
- 连带刷新测试案例文档，补齐近期三项变更：**社保账户**、**买入余额守卫（新建 + 编辑）**、**消费型保险**。

## 四、已知事项

- `tsx --test` 默认**并行**执行多测试文件时，偶发 `investments-direction.test.ts` 文件级失败（`test at ...:1:1`，`'test failed'`），属既有测试框架在共享临时 DB 下的并发竞争，**与本次改动无关**（该文件单独运行 4/4 通过）。串行执行（`--test-concurrency=1`）稳定全绿。建议 CI 以串行或限制并发方式运行 `npm test`，避免误报。
