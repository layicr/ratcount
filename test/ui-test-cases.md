# ratcount · UI 测试案例（UI Test Cases）

> 版本：v1.3 ｜ 范围：界面渲染、布局、交互、响应式 ｜ 执行方式：手动（桌面 + 移动视口）

## 一、概述

UI 测试验证每个页面的渲染正确性、视觉一致性、交互反馈与**移动端兼容**。覆盖登录/注册、应用框架（侧边栏/顶栏/移动导航）、全部业务页面（含收支日历、周期计划、流水导入）、确认框与空态。
